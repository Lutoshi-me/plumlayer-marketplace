# Prefabricated balconies

| name | category | note to bidder | applies when |
| --- | --- | --- | --- |
| Install the supplied balconies | Installation | Balcony suppliers bid supply only, so say whether installation is in your number and at what rate per balcony | any |
| Install the supplied railings | Installation | Railing installation is bought apart from railing supply, so price it by the foot on its own line | any |
| Hoist and set the delivered balconies | Installation | Hoisting sits outside the balcony supplier's number, so say who you expect to hoist and set the units | any |
| Thermal break at the balcony connection | Attachments | Balcony bidders do not carry the thermal break, so say who supplies and installs it at each connection | any |
| Blocking, backing and framing at knife plates and post bases | Attachments | The supplied knife plates and post bases land in blocking and framing by others, so state who carries them | any |
| Waterproof and flash every balcony attachment and railing post penetration | Waterproofing | Every attachment and every post through a deck, a paver system or a parapet is a leak path the balcony supplier leaves out, so say who seals it | any |
| Field measure before fabrication | Coordination | Balcony suppliers put field measurement on the purchaser and fabricate nothing until it is done, so state who measures and when | any |
| Verify balcony counts and dimensions against the drawings | Coordination | Supplied counts and dimensions are the purchaser's to verify and a difference from the drawings becomes a change order, so state the count you carried | any |
| Panic hardware at railing gates | Gates | Gate hardware can be left out, panic hardware in particular, so say whether the gate hardware is in your number | gates in the railing runs |
| Wood slats in pergola and cabana frames | Carpentry | The frame is fabricated to receive slats the balcony supplier does not furnish, so state who supplies and installs them | pergola or cabana frames |
