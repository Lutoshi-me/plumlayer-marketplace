# Masonry

| name | category | note to bidder | applies when |
| --- | --- | --- | --- |
| Install shelf and relieving angles at masonry | Steel in the wall | Angles come from the metals package and their installation is carried by some masons and excluded by others, so state whether you install them | any |
| Install loose lintels at masonry openings | Steel in the wall | Lintels come from others and most numbers are silent on setting them, so say whether setting is in yours | any |
| Top of wall clips, angles and lateral restraint at partitions | Steel in the wall | Excluded on the furnish and the install side by masonry, metals and drywall alike, so confirm who carries it | any |
| Welding at masonry connections | Steel in the wall | Excluded by name by most masons, so any connection needing a weld sits outside the masonry number even where the piece it holds is inside it | any |
| Sill pan flashing, counterflashing and metal copings | Flashing | Excluded by most masons while through wall and base of wall flashing are carried, so confirm who carries the metal half | any |
| Air and vapour barrier behind the veneer | Barriers | Excluded from nearly every masonry base bid on new work, so it has to be bought in the envelope package | any |
| Cavity insulation in the veneer cavity | Barriers | Carried by most masons in whatever the assembly schedule names and excluded by a minority, so state which you do | assembly carries cavity insulation |
| Joint sealants and caulking at masonry | Sealants | Excluded from essentially every masonry base bid on new work and often unassigned, so confirm who carries it | any |
| Exterior and interior expansion joint assemblies | Sealants | Excluded by some masons and often unassigned, so say whether the assemblies are in your number | any |
| Grout at steel columns and beams | Grouting | Masonry shaped work that regularly goes unbid, so state whether you carry it | any |
| Delegated design and engineering for masonry and precast anchorage | Delegated design | Excluded by the mason and by the cast stone supplier alike, so name who engages the engineer | any |
| Building tie-ins and patching around hoists and staging | Cutting and patching | Rarely carried by anyone, so state whether closing these openings is in your number | any |
| Shaped and special brick units | Brick | Bidders regularly say none are shown while the supplier price list carries them, so price the shapes on the elevations or say none were found | any |
| Coloured mortar, pigments and additives | Mortar | White, black and custom colours are excluded by some masons, which leaves a specified colour unpriced, so state whether the colour is in your number | coloured mortar specified |
| Set hollow metal door frames in masonry walls | Openings | About half of masons exclude setting frames, so say whether setting them is in your number | any |
| Winter protection, heat and enclosure for masonry | Winter conditions | Excluded by every masonry bidder on both new and existing work, so confirm who carries it | masonry work in cold weather |
| Sample and mock-up panels | Mock-ups | Priced in the base by some and as an add per panel by others, so state which, and whether the panel stays or is removed | mock-up panel required |
| Site signage masonry | Site masonry | Excluded by most masons and often unassigned, though the owner's bid form may ask masonry to break it out | site signage shown |
| Panel cladding at the garage perimeter | Cladding | Non masonry panel and its flashing land on the masonry sheet because no other package claims them, so state whether you carry them | structured parking with panel cladding |
| Exterior access for facade work | Access | Carried in the base by some, excluded by others and priced as an add by a third, so state which, and the method for each elevation | facade restoration |
| Steel remediation behind removed brick | Existing wall work | Most masons open the wall and close it again without touching the steel, so confirm who repairs it | facade restoration |
| Interior historic stone, marble and tile restoration | Existing wall work | Priced by one specialist and declined by the rest, so say whether it is in your number | renovation of an existing building |
