# Plumbing

| name | category | note to bidder | applies when |
| --- | --- | --- | --- |
| Furnish heat trace cable | Heat trace | Excluded by most plumbing bids and picked up by electrical, a specialty vendor or nobody, so state whether the cable is in your number | any |
| Install and terminate heat trace cable | Heat trace | Answered apart from the cable, so state whether you install and terminate cable furnished by another party | any |
| Insulate over heat trace cable | Heat trace | State whether the insulation over the cable is yours, and note that commissioning readings are taken after it goes on | any |
| Furnish domestic water submeters | Metering | Most bids install submeters and exclude furnishing them, so price the furnish half on its own line | metered units |
| Program submeters to the data collection system | Metering | Assigned apart from the meter itself, so state whether programming is in your number | meter data collection system |
| Underslab and foundation drainage | Site and underground | Excluded by about half the field as site work even where the specification assigns it here, so confirm who carries it | any |
| Hangers and supports for underground and underslab pipe | Site and underground | Specified to the plumber and excluded by the market, so state whether they are in your number | any |
| Excavation, backfill and compaction for plumbing work | Site and underground | Excluded by nearly every bid as site work, so confirm who digs, backfills and compacts | any |
| Water service from the site contractor's stop into the building | Site and underground | State the exact point your service pipe begins so the gap to the site contractor is visible | any |
| Concrete pits, basins, vaults, housekeeping pads and encasements | Concrete and structure | Excluded by nearly every bid while the pump inside is carried, so confirm who forms and pours them | any |
| Vault and basin covers, hatches, grates and ladders | Concrete and structure | Frequently carried by nobody, so state whether covers and access come with your equipment | any |
| Supplemental steel and dunnage for hung plumbing equipment | Concrete and structure | Excluded by most and frequently unassigned, so confirm who supplies and sets the support steel | any |
| Seismic restraints and vibration isolation for plumbing | Concrete and structure | Included by some as code required and excluded by others, so state whether restraints and isolation are in your base | any |
| X-ray and core structural slabs and beams for plumbing penetrations | Concrete and structure | Excluded by some and frequently unassigned, so confirm who scans and cores structural elements | any |
| Power, control and low voltage wiring of plumbing equipment | Electrical connections | Excluded by nearly every bid and often not drawn, so list every float, shutoff, aquastat and control panel that needs wiring | any |
| Utility tap fees, access charges and utility back charges | Fees and permits | Excluded by nearly every bid, so confirm who pays the utility and keep the charges out of your number | any |
| Engineered and stamped drawings, expansion loop and seismic calculations | Engineering | Excluded by most and frequently unassigned, so state whether stamped design work is in your number | any |
| Temporary water, drains and their maintenance during construction | Temporary services | Excluded by nearly every bid and rarely assigned, so confirm who installs and maintains temporary services | any |
| Shower pans and waterproofing below shower bases | Showers | Contested between the plumber, the tile setter and a pan supplier, so price it per shower base mark and per count | any |
| Set undermount sinks in countertops | Fixtures | Furnish and install separate here, so state whether you set undermount bowls or the counter fabricator does | undermount sinks |
| Install bathroom accessories and grab bars | Accessories | Most plumbing bids exclude toilet accessories outright, so state whether the installation is in your number | any |
| Scupper drains, untagged drains and metal downspouts | Drainage | Storm scope is usually bounded to drains that carry a tag, so state how you handled the ones that do not | any |
| Trench drains shown on architectural or civil sheets | Drainage | Routinely excluded here and carried by nobody, so state whether trench drains off the plumbing sheets are yours | any |
| Radon and soil gas vent piping | Specialty systems | Excluded by most and frequently unassigned, so state whether radon and soil gas venting is in your number | radon or soil gas system |
| Rainwater harvesting and greywater reuse piping | Specialty systems | Seen only as an exclusion, so state whether the system is in your number | rainwater or greywater system |
| Pool and water feature piping and equipment | Specialty systems | Excluded from plumbing bids and bought elsewhere, so confirm who carries it | pool or water feature |
| Receive, store and deliver owner supplied fixtures and equipment | Coordination and access | Excluded in two different shapes, so state whether you receive and store, or only install and start up | owner supplied fixtures |
| Install access panels furnished by the plumber | Coordination and access | Nearly every bid furnishes access panels and excludes installing them, so confirm who installs | any |
| Remove and replace ceiling tile for plumbing access | Coordination and access | Excluded by some, so state whether ceiling access and reinstatement is in your number | existing suspended ceilings |
| Cut, patch and saw cut for plumbing work | Coordination and access | Excluded by most, so confirm who cuts and patches for the plumbing rough | any |
| Final cleaning and protection of installed fixtures | Closeout | Excluded by some, so state whether fixture protection and final cleaning is in your number | any |
