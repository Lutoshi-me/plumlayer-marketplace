# Windows

Balcony, terrace and patio doors are the same frame system as the windows: tag them to windows as their own family even where the schedule tags them separately.
Enumerate at the full tag, never the base tag: each handing, each tempered variant, each fixed and each operable variant, and each cladding condition gets its own row.
Read the schedule for its own tag vocabulary; there is no fixed prefix scheme to assume.
Color, finish, hardware, screen type and glazing buildup ride the mark row as attributes; never split a mark on them.
Sashes, vents and lites are a quantity on the mark row, not rows of their own.
Never split window rows by level or floor; the schedule organizes this trade, not the floor plan.
Say which count a number is, types or units or lites; the three run far apart on the same schedule.
Setting the units is a separate package on new construction: tag installation, and the flashing and air barrier tie-in at the opening, to rough carpentry and siding.
Frame extensions, panning, brickmould, sill pan and perimeter flashing drawn on the window detail sheets are not the window supplier's; tag windows and siding both.
Storefront at punched openings, transoms over entrances and infill at louver openings: tag windows and glazing both.
Curtain wall and entrance storefront systems are the glazing package, not windows.
Mirrors, glass guardrails, smoke baffle glass, handrail glass, fire rated door lites and interior glazing go to glazing, not windows.
Skylights, louvers, window washing anchors and facade brake metal or composite panel are not this package.
Shades, blinds and drapery are interior specialties; the word window is a token collision here, not a seam.
Blocking at the openings goes to rough carpentry or drywall; where none is drawn, raise a Question rather than assuming it.
A door with a window integrated above or beside it is one composite tag, not a door row plus a window row.
Where the schedule and the elevations tag the same opening differently, carry both tags on the row and raise a Question.
Where nothing on the schedule matches a mockup opening, give the mockup its own tag.
On renovation, demolition of the existing windows can sit with windows or with demolition; tag both.

coverage: derived from a book drafted on four multifamily projects in one market, all bid by one general contractor; not re-mined.
